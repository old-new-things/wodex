- [nlohmann/json 3.12.0](https://github.com/nlohmann/json/tree/v3.12.0): test harnesses only; vendored single header, MIT license in `external/nlohmann/LICENSE.MIT`. Header SHA-256: `aaf127c04cb31c406e5b04a63f1ae89369fccde6d8fa7cdda1ed4f32dfc5de63`. The application uses Rust `serde_json`.
- [Mozilla CA bundle distributed by curl](https://curl.se/docs/caextract.html): `romfs/cacert.pem`, retrieved 2026-10-19, SHA-256 `a41b5d356aea97a529fe27e0f7316d2f9d946d75927476cf9cf1b90637d00505`. Mozilla's upstream certificate data is covered by the Mozilla Public License 2.0. Update from the public upstream when maintaining releases.
- [SDL2](https://github.com/libsdl-org/SDL) and [SDL2_ttf](https://github.com/libsdl-org/SDL_ttf): zlib license. The optional desktop download is SDL2_ttf 2.24.0, SHA-256 `0b2bf1e7b6568adbdbc9bb924643f79d9dedafe061fa1ed687d1d9ac4e453bfd`; its source archive includes its license.

All rights reserved. The license and additional BDF/PCF notices are in `licenses/native/freetype-2.13.3/`.

- [libnx](https://github.com/switchbrew/libnx): ISC license. The Switch SDK supplies libnx and native library builds; redistribution notices are included in `licenses/native/`.

- Rust crates `serde`, `serde_json` and `sha2`: MIT OR Apache-2.0. Exact versions and transitive dependencies are recorded in `Cargo.lock`. `sha2` provides incremental SHA-256 verification using its software backend on Switch.
- [pulldown-cmark](https://github.com/pulldown-cmark/pulldown-cmark/tree/baa6ac73b677c43c075f5b2b8db0b47897fdc021): MIT; the CommonMark/GFM parser is pinned to an official upstream commit supporting `no_std`, with HTML rendering disabled. `unicode-width` 0.2.2 (MIT OR Apache-2.0) supplies Unicode display widths for code. Their exact dependency notices, including the Zlib-licensed `foldhash`, are in `licenses/rust/`.
- [zune-image](https://github.com/etemesi254/zune-image): `zune-png` 0.5.2, `zune-jpeg` 0.5.15 and `zune-core` 0.5.3 provide portable `no_std` PNG/JPEG decoding with default features disabled. The MIT alternative is selected for these crates and `simd-adler32` 0.3.10; `zune-inflate` 0.2.54 uses its Zlib alternative. Exact license files and the inflater's pinned upstream provenance are in [`licenses/rust/README.md`](licenses/rust/README.md).
- [Noto Sans CJK SC Regular 2.004](https://github.com/notofonts/noto-cjk/blob/Sans2.004/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf): Copyright © 2014–2021 Adobe (http://www.adobe.com/), SIL Open Font License 1.1. The unmodified font, full license and provenance are included in `romfs/fonts/` and packaged into RomFS. SHA-256: `2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b`.
- [Source Code Pro Regular 2.042](https://github.com/adobe-fonts/source-code-pro/blob/803b7e23ec97ae58b6232ea76519a76d428ba268/OTF/SourceCodePro-Regular.otf): Copyright © 2023 Adobe (http://www.adobe.com/), with Reserved Font Name "Source", SIL Open Font License 1.1. The unmodified 131,128-byte font supplies monospaced ASCII code glyphs; CJK text retains the Noto fallback. The font and license are embedded in `romfs/fonts/`, with a duplicate license in `licenses/fonts/source-code-pro-2.042/`. SHA-256: `9f9664e2edf6f045c11e774f9bd0be6993971f2544a39061a5ce478b96b051f8`.

Wodex does not redistribute Nintendo's shared fonts; it opens them through libnx only when falling back from the bundled font. Desktop system fonts are likewise loaded only as a fallback or explicit user override. No wiliwili source code or assets are incorporated.
